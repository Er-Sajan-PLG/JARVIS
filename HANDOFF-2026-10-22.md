## What Was Done

### 1. RISK-026: chromadb CVEs (docs/ACCEPTED_RISKS.md)
Added RISK-026 documenting 4 CVEs in `chromadb` 1.5.9 (latest published, no patched version):
- CVE-2026-45829 (CRITICAL) — pre-auth code injection via malicious model repo
- CVE-2026-45833 (CRITICAL) — authenticated code injection via model repo + `trust_remote_code`
- CVE-2026-45830 (HIGH) — unauthorized data manipulation (improper auth validation)
- CVE-2026-45831 (HIGH) — cross-tenant actions (`SimpleRBACAuthorizationProvider`)

All 4 are **not reachable** in JARVIS's deployment:
- `chromadb.PersistentClient` is embedded (no Chroma server) → pre-auth surface doesn't exist
- Embeddings come from local Ollama → model-repo download path never invoked
- `trust_remote_code` appears nowhere in `app/`
- No RBAC provider configured (single-tenant, Tailscale-only per ADR-020)
