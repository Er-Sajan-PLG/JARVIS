# Jarvis Roadmap

## Vision

Jarvis is a personal AI assistant designed to help with learning, engineering, productivity, research, automation, and daily tasks.

The goal is to build a modular, scalable, and locally controllable AI system that can use local models, cloud APIs, memory, tools, and voice interaction.
